# 战争部长 / Minister of War（暂名）

一款以现代国防装备采购和部队编制为核心的硬核军事战略游戏（1990–2025）。

玩家扮演一个国家的国防部长，在固定的国防预算内采购装备、设计各级编制、扩建军工产能、组织联合演习，并在战争中检验自己的选择。

## 核心设计一览

- **编制**：班 → 排 → 连 → 营模板逐级嵌套；营是最小作战单位，可以自由编成旅、师、集团军。
- **采购**：进口分纯外购、本地组装、全部本地化三种；本国装备可以用预算扩产；装备按历史服役年份出现，不做研发。
- **陆战**：全球 H3 六角格（边长约 23km），战斗发生在地块交界边上；连级条带 + 班级模拟，玩家操作类似 HOI4。
- **空海**：基于 CMO 简化的任务式空战；海军以舰队为单位，防空自动完成。
- **战略**：信任度、紧张程度阶梯、议题支持度、核风险、同盟义务。
