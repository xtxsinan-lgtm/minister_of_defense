# 十二国军力估算：调研计划

目标：用 `forcedb` 同一套方法，估算 **俄罗斯、日本、韩国、朝鲜、伊朗、土耳其、英国、法国、德国、希腊、波兰、以色列** 的军力，
并放进与中美同一把尺子（美国 = 基准，地面 100 / 投送 100 / 空中 200 / 海上 100），不含核力量（沿用文章口径）。
本数据库暂时不影响游戏（游戏只读 `data/equipment|templates|orbat`，本计划只新增 `data/forcedb/` 下的数据）。

## 1. 方法：“类比法”

文章对中美逐型号算战力；对这十二国没有逐型号的技术参数表，直接照搬不现实。折中：

1. **能数的先数**：库存数量取公开清单（Wikipedia 现役装备清单、各国国防部/军种官网、IISS/SIPRI 的公开摘要）。
2. **单位战力用“类比”**：每个型号指定一个库内已有的“类比装备”（同代、同级、同雷达/武器），沿用该装备在文章/表格里的单位战力；
   没有恰当类比时按**等级表**（如：五代隐身 / 四代 AESA / 四代非 AESA / 三代…）取库内同级装备的中位数。
   每个类比记录 `analog_of` 与理由，可逐条审阅和替换。
3. **能直接算的直接算**：水面舰艇 = 垂发单元数 × 折算系数 + 雷达折算；航母用作者空中联队模型（库内已有英/法/日/意/印/西）；
   潜艇用 (装载×续航×吨位/探测距离)^0.25 公式；旅级单位用 基础火力规模 × 五个乘数。
4. **每个估算值带置信度**（stated / estimated / uncertain）和来源链接；总量给出 **低 / 中 / 高** 三档区间（单位战力 ±30%，数量不确定性按来源可靠度）。

## 3. 估算顺序与每国要点

按“数据好找 → 难找”分三批，每批做完就 `build` + 测试 + 推送：

1. **第一批（北约/盟友，数据透明）**：英国、法国、德国、日本、韩国。重点：舰艇垂发与潜艇、F-35/台风/阵风/F-15K 等；日韩的 F-35、宙斯盾/KDX。
2. **第二批**：土耳其、希腊、波兰、以色列。重点：土耳其 F-16 与 TB2/无人机体系；希腊 F-16/阵风；波兰在建的 K2/K9/F-35/爱国者；以色列 F-35I/F-15I/F-16I 与防空多层体系。
3. **第三批（透明度低，区间大）**：俄罗斯、伊朗、朝鲜。重点：俄罗斯的损耗修正（乌克兰战争后现役 vs 库存）；伊朗以导弹/无人机为主、空军老旧；朝鲜以数量庞大的老旧装备 + 战术导弹 + 核（不计入）为主，置信度最低。

## 4. 产出

- `data/forcedb/countries/<ISO3>.yaml`：每国的清单（型号、数量、类比、来源、置信度、日期）。
- 入库：新增装备记录带 `estimate.*` 规格；库存写入 `inventory`（来源 `research_2026`，可靠度 medium/low）。
- 引擎：识别 `estimate.*` 单位战力；`forcedb score --countries RUS JPN ...` 输出同一张对比表；`forcedb estimate-range` 输出低/中/高区间。
- 文档：每国一页要点（假设、置信度、最大不确定性），汇总排名与敏感性分析。
- 推送：每国数据入库、测试通过后立即提交并推送到 `feat/force-db-world`，最后开 PR（依赖 #1）。

## 5. 质量控制

- 每国数量与至少两个来源交叉核对；差异 ≥15% 的写进 `crosscheck` 与国别要点。
- 类比装备的单位战力在报告里并列显示“若换成更低/更高一档类比”的总量变化。
- 所有“常识性录入”标 `manual_general_knowledge`（低可靠度），有可爬来源后被覆盖。
- 不计核力量、不评估人员素质/训练/后勤（沿用文章的 readiness 乘数粗略处理，并在每国页说明）。
