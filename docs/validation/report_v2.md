## 4. 防空电磁态势（Active / Silent）与安-2 诱饵机反事实实验（`08_air_airdefense.md` §9 V2）

1. **前两周防空消耗占比（`armenian_ad_attrited_early`）**：
   - 第 14 天时亚方永久损失的防空导弹系统占整场战争总损失的 **79.4%**（落在 `[50%, 90%]` 目标区间内），复现了开战前两周 Osa-AKM / Strela-10 被安-2 诱饵机诱骗开机并遭 Harop / TB2 集中猎杀的史实过程。
   - **反事实对照（移除安-2 诱饵机 `without_an2_decoys`）**：若阿方不使用安-2 无人诱饵机，亚方前 14 天防空损失占比从 **79.4%** 降至 **69.0%**，总防空损失从 **54 部** 降至 **49 部**。
2. **S-300PS 全程开机（`always_active`）vs 全程静默（`always_silent`）vs 游击伏击开机（`doctrine_mixed`）**：
   - `s300_always_active`：5 部 S-300PS 火控/照射雷达在 Harop 反辐射猎杀下 **100% 损失（中位损失 `5.0 / 5.0` 部）**。
   - `s300_always_silent`：S-300PS 雷达几乎完好保存（中位仅损失 `0.91 部`），但因放弃中空威慑，阿方中空察打一体无人机毫无顾忌地抵近前线，亚方地面装备与前线部队完全暴露。
   - `s300_doctrine_mixed`：间歇开机伏击，完整呈现 `08_air_airdefense.md` 设计的“开机即暴露、静默即失守”真实防空两难。
