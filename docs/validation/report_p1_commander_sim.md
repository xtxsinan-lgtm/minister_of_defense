# P1 验证报告：司令模式作战模拟的史实校准与决策敏感性

- **日期**：2026-10-23
- **代码**：[`web/commander/sim_core.js`](../../web/commander/sim_core.js)（浏览器与命令行共用同一份代码）、数据生成 [`tools/sim/build_sim_data.py`](../../tools/sim/build_sim_data.py)
- **批量推演**：[`tools/sim/calibrate.py`](../../tools/sim/calibrate.py)（JavaScriptCore 运行，每个场景 200 个随机种子）、原始结果 [`tools/sim/p1_calibration.json`](../../tools/sim/p1_calibration.json)、单因素扫描 [`tools/sim/sweep.py`](../../tools/sim/sweep.py)
- **标准答案**：[`data/scenarios/nk_2020/calibration.yaml`](../../data/scenarios/nk_2020/calibration.yaml) 的历史区间

## 1. 模型概要

| 子系统 | 做法 |
|---|---|
| 地图 | 285 个约 12 km 六角格，按真实经纬度生成；国界、1994–2020 接触线、地形为依据公开地图的**人工近似**（仓库内无高程数据） |
| 部队 | 战斗序列（`nk_2010` + `nk_2020` 覆写）× 编制模板 × 两国库存，按优先级分配；未编入模板的库存装备编成临时营（预备役，需动员）。营是地图上的单位，旅是指挥编组 |
| 交战 | 每个被攻击地块一个交战，统一推进距离（DC-023），推进 10 km 或守方组织度崩溃即易手；撤退丢弃部分重装备（计为被缴获），被合围则大部损失 |
| 炮兵 | 交战火力支援 + 每 3 小时一次的炮兵对抗/骚扰射击；阿方经无人机校射效率更高 |
| 空中 | 阿方 TB2 出动与巡飞弹打击；亚方防空覆盖降低命中并击落 TB2；防空纪律（开机/伏击/静默）改变拦截与被反辐射打击的概率；开战头几天有诱饵效应 |
| 补给 | 从补给源经己方地块的连通与路程；车队可选全天候/仅夜间；车队损失消耗战区运输车辆池，进而降低运量 |
| 命令 | DC-010：经旅部约 1 小时，越级指挥营约 3 小时，直属部队 1.5 小时，特种 15 分钟；夜间与组织度低时更慢 |
| 阿方 AI | 按轴线规划：每 6 小时为每条轴线挑 1–3 个力量比最优、靠近目标的地块集中进攻；H 档主攻南线、北线有限、东线牵制，次要轴线完成后抽调兵力；P/B 档轴线更宽、目标选择更灵活，B 档无人机 ×1.35 |
| 亚方 AI | `historical`：防空常开、早期装甲反冲击、预备队随机调动；`competent`：关键城镇（舒沙/斯捷潘纳克特/拉钦）各留 ≥2 个营、白天疏散、夜间调动预备队、不做无谓反冲击 |
| 停火 | 舒沙失守后 1–2 天按“11·10”模式停火；第 30 天后阿方连续 10 天无进展则可能就地停火；越过俄方红线强制停火；第 60 天封顶 |

未通过的两项：
1. **火箭炮损失偏低**：战区内亚方火箭炮总数只有约 78 门（含增援），而 Oryx 的 84 门损失包括全部库存。要么剧本低估了战区内的火箭炮，要么损失口径不同，需要查数据而不是继续调参。
2. **南线城镇顺序**：库巴德利（中位第 18 天）比史实（第 29 天）早，菲祖利/哈德鲁特（第 24–27 天）比史实晚；模拟中阿方沿阿拉斯河谷推进比史实快。

## 3. 决策敏感性（n = 200，舒沙陷落比例越低越好）

| 场景 | 舒沙陷落 | 中位失地 | 说明 |
|---|---|---|---|
| 史实部队 + 史实式指挥 | 91% | 0.45 | 校准基准 |
| 史实部队 + 胜任指挥（防空伏击 + 夜间车队） | 78% | 0.51 | |
| 史实部队 + 胜任指挥（防空开机 + 全天候车队）† | 48% | 0.51 | 单因素扫描，另一组种子 |
| 改进部队 + 史实式指挥 | 80% | 0.46 | +16 道尔、+12 中程防空、+120 重型反坦克导弹、工事 +0.15 |
| 改进部队 + 胜任指挥 | 68% | 0.49 | |
| 改进部队 + 胜任指挥 vs B 档阿方 | 87% | 0.58 | 对手强化后优势基本抵消 |
| 史实部队 + 胜任指挥 + 防空静默 | 79% | 0.51 | TB2 损失 5 架（开机时 11–14 架），装甲损失明显上升 |

† 来自 `sweep.py` 单因素扫描（种子 2000+）；其余来自 `calibrate.py`（种子 1000+）。

**结论**
- ✅ **决策确实改变结果**，且方向基本合理：更好的部队、更好的指挥都降低舒沙陷落概率；对手强化会抵消优势。
- ⚠️ **指挥的影响约为建军的 3 倍**（−38 vs −13 个百分点）。在司令模式下这在意料之中，但对“国防部长”这一游戏定位意味着：P3 的建军决策需要更大的杠杆（例如部署位置、编制改革对满编率与动员速度的影响），否则十年建军会显得不重要。
- ⚠️ **“守住纳卡”（结局 B）几乎达不到**（所有场景 ≤ 5%）：南线头一周的失地几乎与决策无关。玩家开战前预先调整南线部署可能改变这一点，需要试玩验证。
- ⚠️ **反直觉结果**：在当前模型中，“防空开机 + 全天候车队”优于“防空伏击 + 夜间车队”。原因是伏击/静默时无人机转而猎杀装甲，夜间车队的运量损失超过卡车节省。这是否符合现实尚无定论，需要在试玩中观察；战后报告的 AI 基线已改用表现最好的配置，避免高估玩家。

## 4. 已知局限

- 地理为人工近似；地形没有高程，只按区域划分。
- 阿方 AI 只做轴线级规划，不会迂回包抄或主动诱敌；亚方 AI 不会主动后撤收缩战线。
- 空中层只模拟阿方无人机打击与亚方防空，没有亚方空军与阿方有人驾驶飞机。
- 火箭炮损失与南线城镇顺序两项校准未通过（见第 2 节）。
- 参数是在本校准集上调出来的，**存在过拟合风险**；应留出部分指标（例如 2016 年四日战争）做独立检验。
