### 1.4 V1-d：步兵班火器总重 15–18kg 拐点、班人数（7 / 9 / 11 人）与老兵传帮带（`DC-001`）
1. **班组火器重量拐点**：
   - 将班用支援火器重量从 `6kg` 递增至 `30kg`：净战斗效能从 `6kg` 的 `1.625` 上升至 **`18kg` 的峰值 `2.675`**（对应现实 `PKM 7.5kg + RPG-7 6.3kg + 弹药 ≈ 15–18kg`），随后因机枪手负荷超过体重的 45%（`36.3kg–41.5kg`）、机动速度跌至 `0.70–0.78x`、25 分钟接敌冲刺疲劳攀升至 `0.31–0.34`，净战斗力在 `22kg / 26kg / 30kg` 反而倒挂下降至 `2.663 → 2.604 → 2.516`。
2. **班规模（7 / 9 / 11 人）与老兵传帮带（`DC-001`）**：
   - 承受 3 人伤亡后，7 人班组织度上限 `orgCeiling` 跌至 `0.639`（保留战力 `0.301`），而 9 人班与 11 人班 `orgCeiling` 保持在 `0.723` 与 `0.775`（保留战力 `0.563` 与 `0.631`）。
   - 班内混编 2 名老兵（`skill = 0.82`）带领新兵（`skill = 0.35`）时，老兵传帮带机制（`s_eff,i = s_i + 0.30 * max(0, s_max - s_i)`）使 7 / 9 / 11 人班的全班有效熟练度立即提升 **+20.9% / +24.0% / +26.2%**。

## 3. V6：班组交战循环与 `OutcomeCache` 性能基准（`v6_perf_benchmark.py`）

| 指标项 | 实测 / 外推值 | 规范目标上限（`03_squad_combat.md` §9 V6） | 状态 |
| :--- | :---: | :---: | :---: |

| **纯 Python 单场 60 步完整交战耗时** | **30.52 ms**（`508.6 µs/step`） | — | — |
| **C# 单场 60 步完整交战耗时（保守 25x）** | **1.221 ms** | — | — |
