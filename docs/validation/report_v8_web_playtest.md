## 一、V8 网页原型架构与核心功能

为替代传统的静态纸面对话推演（Paper Playtest），V8 网页原型直接打包了 [`data/scenarios/nk_2020/`](../../data/scenarios/nk_2020/) 与 [`data/scenarios/nk_2010/`](../../data/scenarios/nk_2010/) 的全部 JSON 数据以及 V1–V7 数值验证结果（[`data_bundle.js`](../../web/v8_playtest/data_bundle.js)），在纯前端无后端依赖的环境下提供四大交互推演工作台：

### 1. Tab 1：V8 交互推演工作台（2010–2020 十年建军 & 2020 纳卡战争）
- **国家视角与争议地名动态切换（`DS-044`）**：支持在顶栏一键切换 `亚美尼亚共和国 (ARM)` 与 `阿塞拜疆共和国 (AZE)` 视角，地图与战报中的争议地名自动切换各自官方称谓（如 `Stepanakert / 斯捷潘纳克特` $\leftrightarrow$ `Khankendi / 汉肯德`、`Shushi / 舒施` $\leftrightarrow$ `Shusha / 舒沙`、`Karvachar / 卡尔瓦恰尔` $\leftrightarrow$ `Kalbajar / 凯尔巴贾尔`）。
- **兵牌样式实时切换（`DS-027`）**：支持 `NATO APP-6 军标` 与 `高对比度装备剪影 (Silhouette)` 实时切换，满足硬核军迷与大众策略玩家的双重可读性需求。
- **2010–2020 十年建军与整备改革面板（`V4` + `DC-009`）**：
  - 模拟亚美尼亚十年防务预算（基础军费 `\$4,850M` + 俄制优惠军贷 `\$300M`），验证 **`DC-009` 预备役与现役整备改革**如何释放 `\$640M` 自由采购空间；
  - 提供 SHORAD 近程防空、电子战（EW）、防线工事、三代反坦克导弹（Kornet-E）、侦察无人机、弹药储备天数（20/40/60天）与高溢价陷阱（Su-30SM 无弹药奇观机）滑块及 4 组一键预设；
  - 支持在正式进入 2020 大战前，先执行 **2016 四月四日战争前哨检验（`V2b`）**，实时查看塔利什高地与拉勒泰佩高地交火战损。
- **纳卡战区 28 格作战六角格地图与单格 5-Phase Strip 态势检视器（`DC-023` & `DC-022`）**：
  - 实时渲染北线塔利什、东线阿格达姆、南线杰布拉伊尔-哈德鲁特-舒沙河谷走廊及拉钦/佐德双补给通道；
  - 点击任意六角格可检视其 **5-Phase Strip（侦察接触 $\to$ 远火压制 $\to$ 雷场破障 $\to$ 主阵地交火 $\to$ 纵深巩固）**，直观展示 **`DC-023` 单一 `advanceKm` 真实推进条**与 **`DC-022` 合成营自动火炮目标优先级**。
- **战时指挥层级延迟（`DC-010`）与防空电磁静默（EMCON）开关**：
  - 实时对比 `军级主攻命令 (98.0 min)`、`旅级战役协调 (58.8 min)`、`越级直控营级惩罚 (176.4 min, 2.5x+1.2x)` 与 `特种部队直通 (29.4 min)` 对战局的决定性影响；
  - 支持按日步进（`+1 天` / `+5 天` / `推演至终局`）并支持一键导出 JSON 格式的战后复盘报告（AAR）。

### 2. Tab 2：Phase 0 编制试验场 & 班排 60 步动画沙盒（`V1` & `V5`）
- 内置 HTML5 Canvas 2D 实时战术推演画布，动态渲染 `dt = 5s`、共 60 步的步坦协同、雷场破障、炮火压制与翼侧包抄；
- 支持自由组合红蓝双方 16 套编制模板、5 类地形、4 类作战任务、班组携行武器重量（验证 **`18 kg` 机动拐点**）、老兵传帮带（**`DC-001` 消除新兵首战恐慌 `1.50x`**）以及 ATGM 下放层级。

### 3. Tab 3：纳卡后勤网络、拉钦走廊切断与关键节点实验室（`V3`）
- 交互式调节消耗强度（T5 基准 `1,200 t/d` 等 4 档）、走廊开关状态（M12 拉钦 + M11 佐德双通 / 仅 M12 / 仅 M11 / 双切断）与格鲁吉亚禁运状态；
- 实时计算所需车队卡车数、带宽利用率、断粮天数，并并排展示 ARM/AZE 双方 Top-5 `KeyNodeReport` 瓶颈节点与一键整改建议。

### 4. Tab 4：V1–V8 全量数值验证报告与自动审计台
- 汇总展示 V1–V8 全部 8 大验证套件的通过状态、核心指标与交互自检按钮。
